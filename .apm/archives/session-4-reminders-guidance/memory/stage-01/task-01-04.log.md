# Task 1.4 - Apollon Mark & Icon Set

## Summary
Established one coherent Apollon visual identity — the assistant's mark, the app icon, and the notification icon — and produced the full install icon set. The User selected the mark interactively; the Apollo figure is used at every size ≥96px and a paired original "sun" glyph handles the sub-96px surfaces where the figure is too detailed to read.

## Details
- **Selection was interactive, across several rounds.** I first reviewed how the assistant is represented in `frontend/src/features/chat/` (finding no existing mark — the empty state and assistant turns were text/bubble only) and presented three original geometric directions (alpha letterform / solar disc / lyre) in a rendered comparison artifact. The User rejected those and proposed the Hades II Apollo art; I declined that specific asset (Supergiant copyright, and far too detailed for a 32px badge) and offered original alternatives. The User then found and chose the **Noun Project "apollo" by Maxicons (CC BY 3.0)**. I rendered it at every real size (512→16px, tinted, in a notification, as the chat avatar) so the small-size legibility could be judged directly; the User confirmed the mark and set the cutover: **Apollo at ≥96px, sun below.**
- **Asset generation:** cleaned the source SVG (stripped its embedded credit `<text>` nodes), computed the figure's tight bounding box by render-and-trim, and rasterized with a throwaway `sharp` in the scratchpad (no dependency added to the project). Figure sizes sit on a near-black tile with an off-white figure (dark = primary). Verified centering/legibility by reading back the PNGs; confirmed the sun badge reads cleanly at 96 and 32.
- **In-app mark:** `ApollonMark` renders a CSS-masked box over `/apollon.svg` so it paints in `currentColor` and follows the theme without inlining path data or shipping a second colour variant. Applied to the chat empty state (with an "Apollon" accessible label) and as a small, decorative (aria-hidden) avatar beside each assistant reply. Confirmed live with the User on the running app — no layout regression, reads on dark and light.
- **Favicon:** replaced the previous placeholder mark with the sun (adaptive light/dark via an embedded media query), versioned the `<link>` URLs (`?v=2`) to bust the browser favicon cache, and wired `apple-touch-icon`.
- **Attribution:** CC BY 3.0 requires a visible credit — added a credit line in Settings (bilingual, linkified to the Noun Project) and a repository `NOTICE` file.

## Important Findings
- **The app's install/favicon identity is now the Apollon identity.** The previous placeholder favicon was replaced. This is intentional per the Task (one coherent identity for assistant mark + app icon + notification icon), but the Manager should be aware the product's icon is now Apollo.
- **The icon set is produced but not yet consumed by a web app manifest.** The Task scope was to produce the assets and apply the mark in chat; a manifest referencing `icons/apollon-192.png`, `icons/apollon-512.png`, the maskable variants, and `apple-touch-icon.png` is the downstream (Web Push / installability) task. The notification icon (`notification-icon.png`) and badge (`notification-badge.png`) are ready for the push-notification wiring.
- **CC BY 3.0 attribution is a shipping requirement.** The Apollon mark is third-party (Noun Project, Maxicons). The credit (Settings + `NOTICE`) must remain wherever these assets are used; removing it would violate the licence. Only the sun glyph is original and unattributed.
