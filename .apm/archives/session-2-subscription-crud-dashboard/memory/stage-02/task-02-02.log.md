# Task 2.2 - Subscription List, Add/Edit Dialog & Detail Page

## Summary
Built the full Subscriptions CRUD UI — a filterable/sortable table, a react-hook-form + Zod add/edit modal,
status/cancel/delete actions, and the detail page — on top of the Task 2.1 hooks. Verified the CRUD
round-trip live against the running backend. Build, lint, and Vitest (10/10) pass.

## Details
- **Foundation:** Zod schema factory (`createSubscriptionSchema(t)`, i18n-keyed, UX-only) mirroring the
  backend constraints; `formValuesToPayload` maps form values → API payload; shared `Intl` helpers in
  `src/lib/format.ts`.
- **List (`SubscriptionsList`):** shadcn `table` with per-row status `badge`, name links to detail, `⋯`
  actions menu, and an Add button; status/category filters + a sort dropdown joined to an asc/desc arrow, all
  mapped 1:1 to the backend query params (changing them re-keys the query).
- **Add/edit dialog:** one `Dialog` + `react-hook-form` + `zodResolver` serving create and edit; Base UI
  `Select`s via `Controller`; wired to the create/update mutations.
- **Row actions:** edit, pause/resume/reactivate (PATCH status), cancel (soft), delete — all confirmed via
  the shared `ConfirmDialog`; mutations invalidate the `['subscriptions', …]` prefix.
- **Detail (`SubscriptionDetail`):** all fields with literal per-currency amounts + honest placeholders for
  the usage chart/heatmap/cost-per-hour (browser-extension data from a later session).
- **Teaching:** explained react-hook-form + Zod (no generated `<Form>` wrapper) and the Base UI `Dialog`
  modal pattern before building; both recorded in the learning log.
- **UX iteration with User (live):** localized nothing new here beyond keys, but iterated on the filter bar
  styling, added a themed `DatePicker` (Popover + Calendar, DD/MM/YYYY, localized), and added confirmations
  to pause/resume/reactivate — all at the User's request while reviewing the running app.
