# Task 2.3 - Overview Tab (Recharts) & Settings Wiring

## Summary
Built the Overview analytics tab (per-currency tiles + a reusable Recharts spend-by-category chart with
type/currency switchers + renewals/top-expenses lists) and wired the Settings tab (profile form → PATCH /me,
inert notification prefs). Also added a reusable Pagination component across the app and fixed the shell
scroll. Build, lint, and Vitest (10/10) pass; PATCH /me verified live.

## Details
- **Overview (`OverviewPanel`)** consumes `useAnalytics`: per-currency monthly-burn/annual tiles (never
  summed), upcoming renewals (30-day window), top expenses, and the spend-by-category chart. All money/dates
  via `Intl` keyed to the active language; values `Number(...)`-converted from the API's strings; nothing
  re-normalized on the client.
- **Chart (`CategorySpendChart`)** — first Recharts use, built standalone/reusable with three modes
  (horizontal bar / vertical column / donut) and a fixed per-category colour. Followed the **dataviz** skill:
  category = identity → a categorical palette **validated with the skill's script in light and dark**, wired
  through the design system's `--chart-1..5` vars (were grayscale placeholders). Custom themed tooltip. One
  currency per chart — "All" = small multiples; money never converted.
- **Pagination (`components/ui/pagination.tsx`)** — reusable `« ‹ 1 2 … 56 › »`, hidden at a single page.
  Server-side paging on the subscriptions table (limit/offset/total, page size 10); client-side slicing on
  the overview lists (8/page) and per-currency charts (3/page).
- **Settings (`SettingsPanel`)** — react-hook-form + Zod on the `field` primitives (same recipe as Task 2.2);
  display name + language → new `useUpdateProfile` `PATCH /me` mutation (invalidates `['me']`); English/Greek
  applies live. Email shown read-only (not a `ProfileUpdate` field). Notification prefs = disabled switches +
  "Coming soon" badge (backend later).
- **Extras at User request:** brand lockup on all four auth pages (`AuthBrand`); shell fixed so the sidebar
  stays put and only content scrolls; Overview grid `items-start` so the chart card doesn't stretch.
- **Visual collaboration:** presented chart-type + layout options; User steered to a chart-type switcher +
  per-currency selector (dropping cross-currency conversion) — built that. Iterated live on scenarios.

## Important Findings
Three items flagged for the Manager to decide fix + session placement (also saved to agent memory):
1. **Top-expenses cross-currency ranking bug (backend):** `analytics.py` ranks top expenses by raw
   monthly-equivalent across all currencies, ignoring currency — misleading with >1 currency (¥3,000 ranks
   above €50). Recommend per-currency top expenses. Frontend can't fix (only receives the pre-ranked top 5).
2. **Currency conversion (dropped, backend):** User wanted "convert all to one currency"; conflicts with the
   app's no-FX-conversion decision and needs backend FX work. Deferred; built per-currency + single-currency
   filter instead.
3. **Per-subscription provider manage/cancel link:** proposed feature; MVP = user-entered URL (backend schema
   change), AI auto-discovery deferred to the LLM session. User asked the Manager to place it by end of
   Session 2.
- The 6-currency scenario stacks 6 charts under "All" — mitigated with chart pagination (3/page), but the
  Manager may want a product call on defaulting to the top currency instead.
