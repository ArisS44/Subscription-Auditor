# Task 2.4 - Currency Filter on the Top-Expenses Card

## Summary
Added a per-currency filter to the Overview Top-Expenses card, shown only when the portfolio spans more than
one currency, mirroring the chart card's currency selector. Filters client-side before pagination. Build,
lint, and Vitest (10/10) pass.

## Details
- Added `expensesCurrency` state (defaults to the existing `ALL` sentinel).
- Added a `Select` to the Top-Expenses `CardHeader`, gated on `currencies.length > 1`, reusing the exact
  chart-card selector pattern (`SelectTrigger size="sm"`, the `overview.currency.all` label for the `ALL`
  option, the `currencies` list) so the two controls match.
- Filter `data.top_expenses` by the selected currency before the existing `paginate(...)`; `ALL` passes the
  full list unchanged. The `onValueChange` sets the filter and resets `expensesPage` to 1.
- Also switched the card's empty-state check to the filtered list so a currency with no items shows the
  "no expenses" message rather than a blank list (edge-case hardening; in practice every listed currency has
  spend).
- No new i18n keys — reused `overview.currency.all`.
