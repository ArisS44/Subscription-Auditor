# Task 2.4 - Currency Control & manage_url Forms

## Summary
Added three things to the frontend: an opt-in cross-currency conversion control on the Overview
(estimate-labeled), an optional `manage_url` field on the subscription form + a link on the detail
view, and a small non-modal roadmap teaser on the Overview. Verified end-to-end against the live-dev
backend (FX + subscriptions).

## Details
- **Currency control:** new `useFxRates` TanStack Query hook (`frontend/src/hooks/useFx.ts`) wrapping
  `GET /fx/rates?base&symbols`. In `OverviewPanel`, an opt-in Switch + target-currency Select (shown
  only with 2+ currencies). Off by default → Overview is byte-for-byte unchanged (strictly
  per-currency). On → fetches rates (base = target) and derives a summed monthly/annual comparison
  total plus a cross-currency top-expenses re-ranking, all in the target currency. Every converted
  figure is prefixed `≈` and carries an `EstimateBadge` (outline pill + Info icon + tooltip) — the
  treatment the User chose from three options. The FX hook is called unconditionally (Rules of Hooks)
  above the component's early returns; a 503 surfaces as an "temporarily unavailable" inline state, not
  a crash. Per-currency burn tiles always remain visible (real figures); the converted total is
  additive, never a replacement, so a converted number can never be mistaken for a real per-currency one.
- **manage_url:** added to the `Subscription`/`SubscriptionCreateInput` types, the Zod form schema
  (empty allowed = clear; otherwise a well-formed http(s) URL ≤2048 chars, mirroring the backend's
  `AnyHttpUrl` check — UX-only, backend re-validates), the add/edit form (URL input + hint), and the
  detail view (renders an "Open provider page" link, `target=_blank rel=noopener noreferrer`, or "Not
  set"). Extended `subscription-schema.test.ts` with 4 cases incl. rejecting `javascript:` and
  malformed input; full file 13/13 passing.
- **Roadmap teaser:** a slim muted line under the Overview heading (visible without scrolling, per User
  request), signpost icon, no dismiss/badge/modal. Copy iterated with the User: the AI-tool-only and
  the jokey drafts were rejected; final copy frames general subscription usage tracking.

## Important Findings
- **Time-tracking scope broadened beyond the written spec.** While iterating the teaser copy, the User
  clarified their intent: the browser-extension usage/time tracking should cover **as many
  subscriptions as technically feasible**, not AI-tools-only as CLAUDE.md/APP_DESCRIPTION currently
  frame it. This affects the extension design in Sessions 4-7 and should be reconciled with the
  Manager/spec. (Hedge: a browser extension can only measure browser-based/web-app subscriptions, not
  TV/native/offline ones.)
- The converted top-expenses ranking provides a fair cross-currency ordering *only in the opt-in
  converted view*; the default per-currency top-expenses list is unchanged. This relates to the
  previously-flagged cross-currency top-expenses ranking concern but does not itself change the default
  backend ranking.
- Backend note (not blocking): the running dev backend was a stale process started without `--reload`
  and predating the chat/FX routers; it had to be restarted to expose `/fx/*` (and `/conversations/*`).
