# Task 1.5 - FX Service & Conversion Endpoint

## Summary
Built `backend/app/services/fx.py`: a lazily-refreshed, cached FX layer over the existing `fx_rates`
table (12h TTL, refresh inline on first stale/missing request, no scheduler), with service-role writes,
last-known-good fallback on source failure, and `GET /api/v1/fx/{rates,convert}` endpoints. Verified live
against the real Frankfurter source.

## Details
- `services/fx.py`: `get_rate` / `get_rates` / `convert`. A fresh cached rate is served with no external
  call; stale/missing triggers one Frankfurter fetch (`/latest?from=BASE`, all pairs in one call), upserted
  via `db/fx.py::upsert_rates` on the `(base, quote)` unique key. Source failure (`httpx.HTTPError`) →
  `_try_refresh` returns False and the caller serves the last-known-good cached rate; a cold cache + down
  source raises `FxUnavailableError`. `now`/`client` are injectable for testing; a lazy shared
  `httpx.AsyncClient` mirrors the llm.py pattern.
- `db/fx.py`: reads/writes on a plain pooled connection (service role, bypasses RLS) — `get_rate`,
  `max_fetched_at`, `get_rates_for_base`, `upsert_rates` (ON CONFLICT upsert). No new migration (the table
  from Task 1.1 already has the right shape).
- `models/fx.py`: `FxRatesResponse`, `FxConversionResponse`. `routers/fx.py`: `/fx/rates` (base + optional
  symbols) and `/fx/convert` (`from`/`to`/`amount`), auth-required, `FxUnavailableError` → 503; registered
  in `main.py` under `/api/v1`.

## Validation
- `pytest tests/test_fx.py`: 11 tests. Service-layer (real `fx_rates`, mock httpx client, controlled `now`,
  test-only base `XTS`): fresh cache serves with a client that asserts-on-call (proves no external call),
  stale cache refreshes, same-currency identity, conversion math (100 × 0.9 = 90.00; same-currency
  preserved), source-down falls back to last-good stale rate, cold cache + source-down raises, symbol

  `FxUnavailableError`. No APScheduler/background runner introduced. ruff + black clean; secret scan passed.
- Live check against the real source confirmed correct URL/params/parse (USD→EUR=0.87451, 29 quotes).

## Important Findings
- **Frankfurter host moved.** `api.frankfurter.app` now issues a 301 redirect to
  `https://api.frankfurter.dev/v1`, and httpx does not follow redirects by default — the first live check
  failed on the 301. Fixed by pointing `_FRANKFURTER_BASE` at `https://api.frankfurter.dev/v1` and enabling
  `follow_redirects=True` on the shared client. Any other code/docs referencing `frankfurter.app` should be
  updated. This is why the live validation step mattered — the mocked tests alone would not have caught it.
