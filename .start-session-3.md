# Start Session 3 — AI Chatbot & Onboarding

Quick reference for kicking off the next APM session. Run the terminal commands
in order, then start the Planner in a NEW chat.

## 1. Terminal commands (run in the repo root)

```bash
# Scaffold a fresh, blank .apm/ workspace for Session 3.
# (Session 1 is archived at .apm/archives/session-1-foundation/
#  Session 2 is archived at .apm/archives/session-2-subscription-crud-dashboard/)
apm init
```

## 2. Start the Planner (in a NEW chat / new Claude Code terminal)

```
/apm-1-initiate-planner
```

## 3. First message to the Planner — paste this:

```
We're starting Session 3 of the SaaS Subscription Auditor project.

Full project context:
- Project spec: @docs/APP_DESCRIPTION.md
- Session plan: @docs/APM_SESSIONS.md
- Engineering standards: @docs/ENGINEERING_STANDARDS.md
- Cross-session decisions: @docs/DECISIONS.md

This session scope: **Session 3 — AI Chatbot & Onboarding**
(see the Session 3 section in @docs/APM_SESSIONS.md).

Sessions 1 (Foundation & Deployment Pipeline) and 2 (Subscription CRUD &
Dashboard Core) are complete and archived at .apm/archives/session-1-foundation/
and .apm/archives/session-2-subscription-crud-dashboard/ — read their
session-summary.md files (if present) or Memory/index.md for what already
exists: auth, RLS data layer, deployed prod pipeline (S1); the full
subscriptions CRUD + analytics API and dashboard UI, live in production (S2).
Produce a Session-3-scoped Spec/Plan/Rules only, not the whole project.
```

## 4. After the Planner finishes

Start a Manager in this same chat (or a fresh one):

```
/apm-2-initiate-manager
```

Then follow the Manager's dispatch instructions.
