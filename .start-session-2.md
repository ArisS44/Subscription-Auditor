# Start Session 2 — Subscription CRUD & Dashboard Core

Quick reference for kicking off the next APM session. Run the terminal commands
in order, then start the Planner in a NEW chat.

## 1. Terminal commands (run in the repo root)

```bash
# Scaffold a fresh, blank .apm/ workspace for Session 2.
# (Session 1 is already archived at .apm/archives/session-1-foundation/)
apm init
```

## 2. Start the Planner (in a NEW chat / new Claude Code terminal)

```
/apm-1-initiate-planner
```

## 3. First message to the Planner — paste this:

```
We're starting Session 2 of the SaaS Subscription Auditor project.

Full project context:
- Project spec: @docs/APP_DESCRIPTION.md
- Session plan: @docs/APM_SESSIONS.md
- Engineering standards: @docs/ENGINEERING_STANDARDS.md
- Cross-session decisions: @docs/DECISIONS.md

This session scope: **Session 2 — Subscription CRUD & Dashboard Core**
(see the Session 2 section in @docs/APM_SESSIONS.md).

Session 1 (Foundation & Deployment Pipeline) is complete and archived at
.apm/archives/session-1-foundation/ — read its session-summary.md for what
already exists (auth, RLS data layer, deployed prod pipeline). Produce a
Session-2-scoped Spec/Plan/Rules only, not the whole project.
```

## 4. After the Planner finishes

Start a Manager in this same chat (or a fresh one):

```
/apm-2-initiate-manager
```

Then follow the Manager's dispatch instructions.
